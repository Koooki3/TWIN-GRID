# 计划 v2 结果的预先叙述（2026-10-19，在任何 v2 预测之前写成，随 v2 一起冻结）

> 用途：事先规定每一种 v2 读数对应的叙述，防止看到结果后再挑选解释。判定规则以冻结计划 docs/PLAN_V2_COGNITIVE_ZH.md §3.3–3.4 为准；
> 本文件只把规则的每种输出翻译成结论措辞。所有结论都只适用于：Llama-3.1-8B-Instruct / 16k / 预算 1024 / 有单元的 9 个任务（S_unit），
> 而且只在 formal_v2_result = true 时才是正式 v2 结果（cluster/aggregate_v2.py 的输出标志）。

## 1. 每项检验的措辞

| 项 | 读数 | 结论措辞 |
|---|---|---|
| H1 cobs16 − cobs+g2f | Holm 拒绝 | “等内存下，矩类摘要的细网格胜过错位双网格，在 8B 主格上成立” |
| H1 | 不拒绝 | “未在 8B 主格上证实”；同时报告点估计与区间，不写“不存在”，也不写“双网格更好”，除非区间整体 < 0（那时写“点估计与区间方向相反，见 §3”） |
| H2 quest8 − quest16+g2f | Holm 拒绝 / 不拒绝 | 同 H1，换成“box 类摘要” |
| H3 G_cobs − G_quest32 | Holm 拒绝 | “矩类摘要的切分惩罚大于 box 类，在 8B 主格上成立” |
| H3 | 不拒绝 | “未在 8B 主格上证实”；不推出“G 变小”或“8B 不受切分影响”；不作跨模型比较 |
| H3 | 不可估计（in0 或 repair < 50） | “8B tokenizer 下 S_unit 的跨界单元太少，H3 无法检验”，族大小仍为 3，按未判定计 |
| H4（探索性） | 相对标签“小于常数预测” | “在 C 上，结构律 π·G（R = 1）比不含格子信息的常数预测更准（探索性）” |
| H4 | 相对标签“不确定 / 大于常数预测” | “结构律未显示出超过常数预测的样本外预测力（探索性）” |
| H4 | 绝对精度三态 | 原样引用 §3.4 的三种措辞，并注明是“C 上答案单元加权的平均”，不保证每格；与相对标签分开写 |
| H4 | |C| = 0 / 1 / 区间不可判定 | 原样写“不可估计 / 单格（相对标签不适用）/ 不可判定”，附覆盖与缺类别诊断 |

所有项都附：点估计、单项 95% 区间、Holm 调整后的 p（H1–H3），以及注明“没有多重比较之外的控制”。

## 2. 组合情景（对“认识价值”的总体结论）

| 情景 | 条件 | 总体结论 |
|---|---|---|
| V1 全面推广 | H1、H2、H3 都拒绝 | 1.5B 上的三条认识（细分优于错位网格，两类摘要都如此；切分惩罚按摘要类型排序）在 8B 主格上成立。可以写成对免训练选块的设计建议，并注明范围 |
| V2 部分推广 | 恰好一项或两项拒绝 | 只陈述被拒绝的那几项；其余写“未在 8B 主格上证实”。不把部分成立写成整体成立 |
| V3 未推广 | 三项都不拒绝 | “1.5B 上的分解未在 8B 主格上证实”；作为负结果报告，同时提醒 §3.5 的功效风险（效应减半时 H1/H2 的功效约 0.4–0.66），不推出效应不存在 |
| V4 方向相反 | 某项点估计与区间整体 < 0 | 单独报告该项“在 8B 上方向与 1.5B 相反”；这是新现象，只作描述，不改主判定 |
| H4 叠加 | 独立于 V1–V4 | 结构律的结论只作探索性陈述，不能把 H4 写成确证，也不能用 H4 去补强或推翻 H1–H3 |

## 3. 必报项（不论哪个情景）
- 每个臂在 S_unit 上的单元准确率与 G；13 个任务的官方分数（描述）；无单元任务与 UUID 任务分开列出。
- 主格完整性门控与运行描述的 sha256、formal_v2_result 标志、适配验收结论（含平局数）、各块长的显存探测峰值。
- 偏差：任何中断与续跑、OOM、资源设置；任何与本文件或冻结计划不一致的地方。
- 辅助格（其它长度、预算、Qwen2.5-7B、mean 两臂）只作描述，不改主判定。

## 4. 不会做的事
- 不因结果追加样本、臂、任务或改动分析集合；不在看到结果后换主比较。
- 不把 v2 与 v1.4 或 rep2 的数字放进同一个检验；跨模型或跨预算的比较只作描述。
- 不声称速度、显存或吞吐收益。
