# 把块选择收敛为“看极值、不切单元、跟指针”

> **修订说明（2026-10-16，依 Codex milestone-phase1-em-review D/C1/C2 修订）**：统一原则改标为工作假说；删去“切开信息单元是矩摘要失败的主要原因”“只有极值摘要还能捕获残片”；“没有人做过”一律改为“本次检索范围内未见”；本地 COBS 式结果不再称为对 COBS 的反例；EM 只称经典有效上界、数值上不比 Quest 松，不称有限块最紧，跨块长须保留 log n；盒中点推断均值作废；em+g2f 摘要量约 150% Quest-16；删去固定样本量“发表门槛”；REM 只作高斯参照交叉尺度；Bennett/Hoeffding 式号与 BKL 公式映射未逐条核对，不写成出处等价已完成。KVFetch 的机制证据针对 KV 驱逐，本项目保留全 KV 且 +ftail 用了答案标签，二者只是相关假说，不能直接移植。

**结论先行：** 2025–2026 年的文献已经覆盖了我们一半的“新发现”。“均值摘要会稀释块内尖峰”被 RBS-Attention 命名为 mean dilution，并用“质心 ∪ 半径救援”取并集来修补 ([RBS](https://arxiv.org/html/2609.20971v1))。“复制到一半断掉、保留后继 token 就能救回”被 KVFetch 命名为 sequential forgetting，并用读指针加后继预取来修补 ([KVFetch](https://arxiv.org/html/2610.08811))。定理 1 本质上是 Samuelson 不等式与 Bennett–Hoeffding 两点极值的组合，F_n 与 REM 截断分析的有限 n 情形思路一致（公式映射尚未逐条核对） ([Samuelson](https://en.wikipedia.org/wiki/Samuelson%27s_inequality)、[Pinelis 复述 Bennett/Hoeffding](https://ar5iv.labs.arxiv.org/html/0902.4058)、[BKL 2002](https://projecteuclid.org/journals/annals-of-probability/volume-30/issue-2/Fluctuations-of-the-free-energy-in-the-REM-and-the/10.1214/aop/1023481004.full))。另一半仍然站得住，而且彼此连得起来。第一，在已核查的文献里，在本次检索范围内未见“输入、块长、预算都不变，只平移网格”的受控边界实验（未见不等于没人做过）。第二，同样未见“切分方式 × 摘要类型”的交叉实验。第三，也未见在**等摘要内存**下拿 Quest-16 和 COBS 比较。第四，没有人给出由“精确离群项 + Jensen 下界 + 盒/Edmundson–Madansky 上界”构成的块 log-sum-exp 认证区间。因此我们不该把论文写成“我们发现了矩摘要的弱点并提出并集”，而应写成一个统一原则：**块分数必须是块对数质量的可认证上界，所以摘要要看得见少数极端 token；划分不能切开信息单元；选择要跟随复制读指针。** 双网格、强制尾块、Quest-16 的优势，都是这条原则在三个维度上的投影。按这条原则可以直接导出一个候选打分器，即“均值 + 盒”的 Edmundson–Madansky 上界，再配双网格和后继感知，并做 2×2×2 析因验证。眼下最大的短板不在方法，而在统计：11、29、34、40 这样的样本量支撑不了论文级结论。

## 2026 年的三篇论文已占据“矩 vs 极值”的主干叙事

最直接的对手是 **COBS**（2607.09052，2026-07）【全文】。它在每个 32-token 块上存均值 key 和秩 r=4 的块内协方差，再投影到 query 子空间并用 FP4 量化。打分是二阶累积量展开 ln m_b ≈ ln L + qᵀk̄_b + ½qᵀΣ_b q。在 32k RULER 上，COBS 得 **0.8195**，NSA+Quest(min/max) 只有 **0.5765**，mean-pool 为 0.5554，dense 为 0.9040，精确质量 oracle 为 0.9010 ([COBS](https://arxiv.org/html/2607.09052v1))。有两点对我们至关重要。其一，COBS 用的是**自训练的 1.2B NSA 模型**（L=32、top-16 块，经过 RULER SFT），不是冻结的现成模型。其二，它的 Quest 基线同样用 32-token 块，论文没有分析边界、重叠块或并集，也没有给二阶截断的误差界。我们“冻结 Qwen 上 Quest-16 在等内存下最强（0.838）”的结果，由于算法实现与设置都不同（本地 COBS 式打分器 vs 训练过的 COBS 模型），它**不构成**对 COBS 经验结论的反例，只说明该结论向冻结模型的迁移范围尚待验证；写作时要把块长、预算和内存核算写清楚。

**RBS-Attention**（2609.20971，2026-09）【全文】是“并集”主张的终结者。它为每块存质心 c_b 和最大半径 r_b，base 分支用 qᵀc_b 打分，rescue 分支用 qᵀc_b+‖q‖r_bβ_b 打分，两个分支各自过阈值后取 **mask 并集**。在等 5.34% 密度的消融里，并集得 **76.67**，仅质心 73.63，Quest-style 73.71，完整 L2 上界 72.41。论文还发现，半径最大的五分位块里包含 39.5% 的 top-5% 注意力块 ([RBS](https://arxiv.org/html/2609.20971v1))。不过 RBS 只做 prefill，块长 128，预算由阈值决定而不固定，使用各向同性 L2 半径，也没有讨论跨块 token。**CEDAR**（2609.07237）【全文】则把“均值 + 离散度”写成输出误差界（Proposition 1）。去掉离散度优先级后，RULER 从 87.1 降到 84.9；它的 §2.2 明确提出 “attention recall is not enough” ([CEDAR](https://arxiv.org/html/2609.07237v1))。三篇一起，把“块内离散度必须进入打分”变成了 2026 年的共识。

划分这条线的主流叙事是“固定块会切断语义”。**LycheeCluster**（2603.08453，ACL 2026 Findings）【全文】按四级分隔符贪心切分，每块 8–16 token。它的 pilot 在**相同打分**下把 Quest 固定 16 页换成结构感知分块，平均提升 **+10.6%**，JSON 抽取提升 +15.0% ([LycheeCluster](https://arxiv.org/html/2603.08453v1))。**DynSplit-KV**（2602.03184）【全文】报告，刚性切分相对 full KV 掉点 5.5%–55.1%，但变长块会带来 73.1% 的额外开销 ([DynSplit-KV](https://arxiv.org/html/2602.03184v1))。SemantiCache 在 Llama-3-8B、LongBench、20% 预算下，语义分块得 30.01，固定 64 分块得 28.22 ([SemantiCache](https://arxiv.org/html/2603.14303))。NSA 的压缩分支采用 l=32、d=16 的重叠窗口，原文理由是 “mitigate information fragmentation”，但论文没有做 stride 消融 ([NSA](https://arxiv.org/html/2502.11089))。这些证据都混入了块长分布、块数和预算的变化。在检索范围内未见在输入固定的前提下只移动边界的实验。

机制这条线的关键证据是 **KVFetch**（2610.08811，2026-09，单作者预印本）【全文】。按内容打分的 KV 选择会保留答案片段的开头，却丢掉“单独打分普遍偏低”的中段后继 token。复制进行到第 j+1 个 token 时会 “fails irreversibly”。在 RULER-16K（Qwen2.5-7B）的逐字复制子任务上，SnapKV 类方法得 0.8，**Quest 8.8**，KVFetch 78.4，full KV 99.2。作者把 Quest 稍高的分数归因于页粒度“顺带加载了一些后继”，但没有研究粒度 ([KVFetch](https://arxiv.org/html/2610.08811))。它的修复办法是取每步 attention 峰值作为读指针：峰值在 8 步内前进不少于 2 次即进入 copy mode，然后预取指针之后的位置。这几乎就是我们“强制保留尾块”的在线版本。

## 定理 1、F_n 与“并集”必须降格，定理 2 需要升级

**定理 1 不能作为新数学结果。** 它的上界由两部分拼成：Samuelson 不等式 x_i−m ≤ s√(n−1)，n−1 个点相等时取等 ([Samuelson](https://en.wikipedia.org/wiki/Samuelson%27s_inequality))；以及 Bennett(1962)/Hoeffding(1963) 在 X≤y、方差固定条件下由两点分布取到的 MGF 界 ([Pinelis 复述](https://ar5iv.labs.arxiv.org/html/0902.4058))。下界是 Chebyshev 系统矩问题的经典结论，也是 Cîrtoaje 等变量定理的特例 ([Cîrtoaje 2007](https://emis.dsd.sztaki.hu/journals/JIPAM/article828.html)，仅摘要)。调研在本地做了数值核对：n=7、s=1.3 时，n 乘以 Bennett 界再取 log 等于 φ_n(s)=3.3207224459，到机器精度一致；2 万组随机和重尾样本均未违反该界。这只是数值检查，不算文献证据。改写方式是：“我们把经典两点极值（Samuelson–Bennett）重述为 log-partition 的紧界，并据此指出，只存（均值, 方差）的块摘要在最坏情况下不可辨识，误差为 Θ(s√n)。”这一解读，即它是 COBS 类二阶摘要的最坏情况反例，调研未见先例，可以保留为贡献。

**F_n（REM 截断近似）也要降格。** “最大项 + 截断其余项”与 Bovier–Kurkova–Löwe 对 REM 自由能涨落的分析思路一致（BKL 本轮只读了摘要，公式映射待核对） ([BKL 2002](https://projecteuclid.org/journals/annals-of-probability/volume-30/issue-2/Fluctuations-of-the-free-energy-in-the-REM-and-the/10.1214/aop/1023481004.full))，Ben Arous–Bogachev–Molchanov 研究过指数和的 LLN/CLT 临界点 ([BBM 2005](https://eprints.whiterose.ac.uk/id/eprint/86345/))，两者本轮都只读了摘要。可以保留的是它对 COBS 的诊断：高斯近似下的相变点约为 σ≈√(2 ln n)。σ 较小时，退火式 log n + m + σ²/2（即 COBS 的二阶形式）准确；σ 越过该点后，log Z ≈ m + σ√(2 ln n)，σ²/2 会严重高估。按 n=32 算，阈值约为 **2.63**。这是由经典结论代入得到的推断，常数仍需对照 BKL 全文核对，但它把“COBS 何时失效”变成了可以在真实 Qwen key 上测量的预测。另外，2025-12 的 top-k TV 论文已给出高斯分数模型下的尾质量闭式 ([2512.07647](https://arxiv.org/abs/2512.07647))，所以“高斯近似估块质量”本身也不新。

**“并集”不能作为新结构。** RBS 已经对两分支 mask 取并集，SeerAttention 已经拼接 max/min/avg 三种池化 ([SeerAttention](https://arxiv.org/html/2410.13276v4))，CEDAR 消融过每块存两个摘要（87.1→87.6，速度从 3.02× 降到 2.71×），vAttention 已经论证 top-k 与采样互补 ([vAttention](https://arxiv.org/html/2510.05688v2))。我们能保留的说法要窄得多：在 decode、**精确固定预算**下，二阶矩与逐通道盒的错误互补**由边界跨越解释**。“均值摘要漏检”的机制命名应引用 RBS 的 mean dilution，不要自创新词。

**“细粒度页更好”和“离线指标失效”也需要改写。** Quest 默认用 16 页，Sparse Frontier 经消融也选了 16，ArkVale-16 在紧预算下优于 ArkVale-32，MoBA 也报告细粒度更好 ([Sparse Frontier](https://arxiv.org/html/2504.17768v3)、[MoBA](https://arxiv.org/html/2502.13189v1))。所以“16 比 32 好”不新，新的只有“**等摘要内存**”这个比较轴，因为上述工作都是等 token 预算。关于离线指标，CEDAR、HELMET ([2410.02694](https://arxiv.org/abs/2410.02694)) 和 KVFetch 都已有类似论述。我们还必须正面化解与 COBS 的张力：COBS 的精确质量 oracle 达到 0.9010，几乎等于 dense。合理的写法是区分两层。“按真实块质量选”这一**准则**是对的；被打破的是“质量捕获率或 needle 块命中”这类**代理指标**与近似选择器之间准确率差异的对应关系。原因是“命中半个答案”也会被计为命中。

**定理 2（认证区间）最可能是真正的新颖点，但要升级。** 它的组件都已有先例：Jensen 下界相当于 CEDAR/NSA 的“均值 logit + log n_c” ([CEDAR](https://arxiv.org/html/2609.07237))，盒上界来自 Quest。把它们组合成块 LSE 的认证区间，调研未见先例。**白化半径界**的新颖性中等：欧氏版已由 RBS 和 CEDAR 给出，Mahalanobis/leverage 版未见。最值得补的是 **Edmundson–Madansky 上界**：E e^X ≤ ((b−μ)e^a + (μ−a)e^b)/(b−a) ([Madansky 1959](https://doi.org/10.1214/aoms/1177706203)，未核读)。在只知道均值和区间的条件下，这是最紧的上界，而且严格优于“只用盒最大值”的上界。

## 新增的基线与必须达到的统计规范

审稿人一定会要的基线有七个，每个都对应我们某项主张的“更简单的替代解释”。**LycheeCluster 式分隔符对齐块**（8–16 token）用来检验：双网格的收益是否只是“避免切开数字”，而这件事分隔符对齐也能做到 ([LycheeCluster](https://arxiv.org/html/2603.08453v1))。**Quest-16** 是等内存下的现任最强基线，必须作为主比较对象。**KVFetch 式读指针后继预取**用来检验：强制尾块的收益能否被一个在线、无需 oracle 的机制复现 ([KVFetch](https://arxiv.org/html/2610.08811))。**RBS 质心 ∪ 半径**需要改造到 decode，并换成固定预算版本，用来检验我们的“矩 ∪ 盒”是否优于已发表的并集 ([RBS](https://arxiv.org/html/2609.20971v1))。**SnapKV 式邻域扩张**，即对块分数做 1D max-pool ([SnapKV](https://arxiv.org/html/2404.14469))，是双网格最便宜的对手：如果“选中块的相邻块也算选中”就能达到同样效果，双网格的结构意义就会被削弱。**训练无关的 NSA/InfLLM-V2 式重叠打分聚合** ([InfLLM-V2](https://arxiv.org/html/2509.24663v1)) 用来回应“这只是 stride<window”的质疑。**精确质量 oracle（COBS 的 OSA）** 和 **ArkVale cuboid-mean** 分别给出准则上限和包围体的另一种取法。

评测上采用 Sparse Frontier 模板。decode 按**内存传输量**对齐成本，并显式计入摘要读取，因为各方法的摘要开销不同。每个配置至少 100 个样本；16k 和 32k 作为分开的比较族，因为同一固定预算在两种长度下对应的稀疏度不同 ([Sparse Frontier](https://arxiv.org/html/2504.17768))。主检验预注册为精确条件 McNemar。按 Fagerland 等的结论，mid-p 版本功效更高、第一类错误基本受控，作为预注册的敏感性分析，不在事后切换 ([Fagerland 2013](https://bmcmedresmethodol.biomedcentral.com/articles/10.1186/1471-2288-13-91))。区间用 Newcombe 配对 score 区间 ([Newcombe 1998](https://pubmed.ncbi.nlm.nih.gov/9839354/))，不用 CLT。Bowyer 等指出，样本少于几百时 CLT 区间会显著过窄 ([2503.01747](https://arxiv.org/abs/2503.01747))。次要比较做 Holm 校正，样本量按 Connor 公式由预估不一致率决定，而不是由准确率决定 ([Connor 1987](https://www.jstor.org/stable/2531961))。**haystack 独立性**是我们最容易被抓的漏洞：若多个 prompt 共享 haystack 文本或 needle 模板，McNemar 的独立对假设就不成立。每个 prompt 应使用独立的 haystack 种子；否则要预注册按 haystack 的聚类 bootstrap ([Miller 2024](https://arxiv.org/abs/2411.00640))。开发种子与确认种子必须分离，这与 KVDiagnosis 的独立测试集原则一致 ([KVDiagnosis](https://arxiv.org/abs/2608.09412))。解码统一用贪心。

现有数字必须按这个标准重估。“跨边界 2/11 vs 不跨 24/29”是方法内的跨组比较，不是配对比较，只能作为假说生成。“cobs 26/40→34/40”和“COBS 11→27/34”是配对比较，但 N 太小，必须报告不一致对数，并在新种子上重做确认。外部效度方面，NoLiMa 显示 13 个模型里有 11 个在 32K 时降到短上下文基线的 50% 以下 ([NoLiMa](https://arxiv.org/abs/2502.05167))，而按 key 打分的块选择很可能正依赖字面重合。因此至少要加一组低词汇重合的 needle。Sparse Frontier 还发现 Quest 在合成 NIAH 与自然语言 story 检索上表现相反，所以也应加一个自然语言检索任务，避免结论只在字面数字 needle 上成立。结果必须按任务类型、needle 深度和**答案相对块边界的偏移**分层报告，并给出“块命中 × 答案正确”的 2×2 表，而不是只给命中率 ([Pitfalls of KV Compression](https://arxiv.org/abs/2510.00231))。

## 一条原则导出打分器、划分和预算，以及实验优先级

统一原则（**工作假说，尚未证实**）可以写成一句话：**块选择是在预算约束下最大化“读指针未来需要的信息单元”被覆盖的概率，块分数取块 log-质量的上界一端。** “可认证”是候选性质，不是已证明的必要条件；RBS 的 rescue 在 β<1 时并不保证是上界，不能用来支持这条。由此提出三条待检验的推论。

**(i) 摘要要看得见少数极端 token。** 定理 1（经典两点极值）说明，只存均值和方差时，块质量在最坏情况下有 Θ(s√n) 的不确定性。在独立高斯参照模型下，σ 超过约 √(2 ln n) 后质量由最大项主导；这是参照交叉尺度，有限 n=32 的 log-sum-exp 是平滑的，没有热力学意义上的尖锐相变，也不能直接搬到相关、非高斯的 Qwen logits 上。

**(ii) 划分最好不切开信息单元。** 被切开的数值在任一块里只占少数 token，均值可能稀释它。但这不是“只有极值摘要还能捕获残片”：网格平移实验中，Quest 在答案被中间切开时同样明显受损（25→14）。而且平移网格也改变了邻域分组，纯切分的因果作用尚未分离。

**(iii) 选择要感知后继。** 复制是读指针单调前移的过程，下一步需要的块往往单独打分很低。

双网格、强制尾块、Quest-16 的细粒度极值，各自只满足其中一条，所以单独都有效、彼此又互补。这同时解释了我们最难看的一个结果：离线“块命中”或“质量捕获”预测不了准确率，因为它们在单一时刻衡量覆盖，而真正需要的是**沿解码时间的答案片段覆盖**。

推论 (i) 导出一个干净的候选打分器。每块存均值 key 和逐通道 min/max 盒。前者给出块平均 logit μ = qᵀk̄ 的精确值，后者给出块内 logit 的上界 b（Quest 分数）和下界 a。Edmundson–Madansky 给出 Σe^{s_i} ≤ n·((b−μ)e^a + (μ−a)e^b)/(b−a)。当 b−a 较大时，它的对数近似为 **log n + b + log((μ−a)/(b−a))**，即“**Quest 分数 + 均值位置修正**”。这是经典有效上界的新用法（不是新不等式），尚未有端到端结果。它有三个性质。它把矩摘要和盒摘要放进同一个上界，而不是启发式并集。它在数值上不比 Quest 的盒上界更松；但更紧的上界不保证排序更好（例：真值 10、0 的两块，旧上界 11、12，新上界 10、11，仍把第二块排前），必须由实验检验。它对“均值贴近下界、只有一个尖峰”的块保留极值，对“整体偏高”的块给出更紧的分数。配合 Jensen 下界，块 log-质量落在 [log n + μ, log n + U] 内；跨块长比较必须保留 log n。“最紧”只对“任意权重、只约束均值和区间”的分布类成立；n 个等权 token 时端点比例 nw 未必为整数，通道盒还有更多几何约束，所以不宣称对有限块问题最紧。代价是每块存 3 个向量，Quest 存 2 个：单网格 EM-B32 的摘要量约为 Quest-B16 的 75%，双网格 em+g2f 约 150%，不能称等内存。用盒中点推断均值以省第三个向量**不可用**：它破坏精确均值前提（反例：一维 32 个 logit，1 个 0、31 个 1，中点 1/2 给出 (1+e)/2，小于真实的 (1+31e)/32）。推论 (ii) 导出两种做法：等预算双网格（已有证据），以及按分隔符或数字串对齐的切分。推论 (iii) 导出读指针后继预取：检测到 copy mode 时，把指针块的下一块计入预算。

下一步实验按优先级排列如下。

| 优先级 | 实验 | 目的与判定标准 |
|---|---|---|
| P0 | 统计地基：按功效规划定 N（第一阶段试点给出 Δ=0.08 时 198–292，拟定 N=300），记录 haystack 来源窗口并限定推断总体，开发/确认种子分离并预注册 | 精度取决于独立单位、不一致数、效应和推断目标，不存在“N 低于某值就不能发表”的固定门槛 |
| P0 | **受控边界平移**：prompt、块长、预算都固定，只把网格偏移扫过 0..L−1（或固定答案相对边界的位置），交叉矩、盒、EM 三类摘要 | 检验“边界 × 摘要类型”交互这一核心新主张；预期矩类在跨边界偏移上掉点、盒类较平 |
| P1 | **2×2×2 析因**：摘要 {矩/COBS, EM 上界} × 划分 {单网格, 双网格} × 后继 {无, 读指针预取}，全部在等内存、等读预算下，以 Quest-16 为参照 | 检验三条原则是否可加、是否各自必要；以“统一方法在配对检验下超过 Quest-16 的 0.838”为成功标准 |
| P1 | 七个新增基线：LycheeCluster 分隔符块、KVFetch 预取、RBS-decode 并集、SnapKV 邻域扩张、训练无关重叠聚合、OSA oracle、ArkVale cuboid-mean | 排除“只是避开切分 / 只是选相邻块 / 只是已有并集”的替代解释 |

| P2 | 机制 H1/H2：teacher forcing 逐位 oracle，记录复制 head 的源位置所在块的排名；检验“干扰替换数字 = 干扰 needle 中匹配前缀的后继”的 induction 预测；对尾块做 attention knockout | 区分“尖峰被均值稀释”与“数字搭着关键短语块的便车”，回应 attention-is-not-explanation 式质疑 ([Jain & Wallace](https://arxiv.org/abs/1902.10186)) |

| P3 | 外部效度：NoLiMa 式低重合 needle、multi-value、自然语言 story 检索、32k；换一个按三位一组分词的模型（Llama-3 系） | 预测：数字占的 token 更少、跨块概率更低，矩类与盒类的差距会缩小 |

## 结论

调研改变的不是我们的结果，而是这些结果的分量。单看任何一个现象（矩摘要漏尖峰、并集互补、尾块救回、细页更好），都已经有 2026 年的同行占了位。在本次检索范围内（截至 2026-10-16），未见把它们看作**同一个对象的三个投影**的工作：块 log-质量的上界，加上信息单元的完整性和读指针的时间连续性。未见不等于没人做过，这只是候选贡献；这种统一视角如能成立是贡献，而且可以证伪。如果 P0 的边界平移实验不出现“边界 × 摘要”交互，或者 P1 的析因显示三条原则的效应不可加，这个框架就应当放弃，退回成一篇诚实的冻结模型诊断论文。

定位措辞建议如下：“以往工作（COBS、RBS、CEDAR）把块选择失败归因于摘要的阶数不足，并通过加入二阶矩、半径或并集来修补。我们在冻结模型上固定输入与位置、只平移选块网格，发现答案相对网格的位置与选块失败显著相关；两种网格偏移策略之间差异明显，但平移同时改变了邻域分组，纯切分的因果作用尚未分离。我们提出‘切分方式 × 摘要类型’的交互作为待检验假说，它可能统一解释先前文献中均值与 min/max 排序相互矛盾的结果。在方法上，我们用经典 Edmundson–Madansky 界给出块对数质量的上界打分，配合等预算双网格划分与读指针后继感知，在明确核算的摘要内存下与 Quest-16 做配对比较。”经典不等式要明确致谢，不要称为“定理”；新颖性落在**受控实验设计、交互效应、等内存比较和认证区间**这四处，每一处都有本报告引用的文献作为对照背景。
